Nocturnal NOCT

A privacy coin. Confidential amounts, hidden senders, unlinkable addresses.

What it is

Nocturnal is a Monero-style privacy coin. Amounts are hidden by Pedersen commitments with Bulletproofs+ range proofs, senders by CLSAG ring signatures, and recipients by one-time stealth addresses. Proof of work is RandomX, which is designed to run on ordinary CPUs rather than specialised hardware.

The cryptography is deliberately not novel. It uses the monero-oxide crates — Monero's reviewed construction — so that it can be audited by comparison against a system that has been attacked for a decade. What is new here is the surrounding chain, and that is the part being tested.

Confidential amounts

Pedersen commitments, aggregated Bulletproofs+ range proofs.

Sender ambiguity

CLSAG ring signatures over exactly 16 members.

Unlinkable recipients

One-time stealth keys; subaddresses under one view key.

CPU mining

RandomX, 120-second target, ~1,000,000 NOCT asymptote.

Run a node, mine on the testnet

Testnet coins are worthless by design — the point is to find bugs before real money is involved. Build from source with a pinned Rust 1.82 toolchain. The project is Nocturnal and the ticker is NOCT; the programs and crates are named noct*, which is the same thing shortened, not a different project. 

cargo build --release -p noct-wallet --bins
cargo build --release -p noct-node --features randomx

noctd --network testnet --data-dir ~/.noct-testnet
noct-cli new --network testnet --wallet testnet.key
noct-miner --address <YOUR_TESTNET_ADDRESS> --node 127.0.0.1:19334

The RPC is an administrative surface — it can start mining and submit blocks — so keep it on loopback, or set a token and serve it over TLS. A node refuses to start with an unauthenticated RPC on a non-loopback address.

Status and risks

Stated plainly, because you should be able to find this without digging.

  • Not launched. This is a testnet. Coins have no value and the chain will be reset before mainnet.
  • Unaudited. There have been eighteen internal security-review passes and one independent model review, which together found and fixed real bugs — including an 8.79-second denial-of-service and a fork-choice rule that disagreed with consensus. No professional audit has been commissioned. Internal review is not a substitute for one.
  • 50% premine. The planned genesis block mints 500,000 NOCT — half the supply parameter — to the founder. This is a deliberate policy decision, not an accident, and it is the single most consequential economic parameter in the project. Judge it accordingly.
  • Placeholder parameters. The genesis timestamp, mainnet address tags and RandomX seed schedule are not final.
  • Consensus is young. The chain, its reorg handling and its peer-to-peer layer are all new code. The cryptography is borrowed and well-reviewed; the machinery around it is not.

The protocol specification and the full internal security review — including every bug found, and the ones the author got wrong — are in the repository. They are written for an auditor rather than for marketing.
