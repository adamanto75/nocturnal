v0.3.13-testnet — a payment nobody will ever see is not a payment. Acceptance is a statement about one node's mempool, not about the network: on a node with nowhere to dial, or one stranded on its own fork, every send is accepted, mined and worthless — you get a txid and a confirmation, and the recipient is never paid. The wallet and noct-cli now say so on the receipt. Also: the desktop wallet would hand you a fresh receiving address even when it failed to record having issued it, which is how funds arrive at an address the wallet never looks at; it now issues nothing rather than forget. v0.3.0 changed consensus: a node older than that cannot follow the current testnet chain, so if you are running v0.2.x or earlier, update or you will simply stop syncing.

Mining? noct-miner and noct-poold changed with no behavioural change — their sources are untouched since v0.3.12 and they rebuilt only because they link the node crate.

The installer is not code-signed, so SmartScreen will warn, and it is not reproducible — Electron packaging is not deterministic, so its checksum proves only that your download arrived intact, not what is inside it. The command-line binaries it bundles are reproducible, and are the same ones in the archives above.

The checksum proves the file arrived intact. Whether the binary matches the source is a separate question, and from v0.1.4 you can answer it yourself for Linux: see reproducible builds. Releases up to v0.1.3, and Windows builds generally, are not reproducible — for those you are still trusting the author, and building from source remains the correct instinct. The Windows binaries are not code-signed, so SmartScreen will warn you.

Build from source

Rust is pinned to 1.85.1 — the shielded pool’s orchard dependency requires it. The randomx feature needs cmake and a C++ toolchain.

git clone https://github.com/adamanto75/nocturnal
cd nocturnal/noct

cargo test --workspace                                # 578 tests
cargo build --release -p noct-wallet --bins           # noct-cli, noct-walletd
cargo build --release -p noct-node --features randomx # noctd, real PoW

Without --features randomx, noctd builds with a Keccak placeholder proof of work and cannot validate the real chain. It will reject every block. To sync a live network you need the RandomX build.

Run a testnet node

noctd --network testnet --data-dir ~/.noct-testnet
noct-cli new --network testnet --wallet testnet.key
noct-miner --address <YOUR_TESTNET_ADDRESS> --node 127.0.0.1:19334

The node RPC is an administrative interface: it can start mining and submit blocks. Keep it on loopback, or set a token and serve it over TLS. noctd refuses to start with an unauthenticated RPC bound to a non-loopback address.

Back up your seed phrase

A new wallet prints a 24-word phrase. It is the only way to recover the key. Write it down offline. Anyone holding it holds the coins.
