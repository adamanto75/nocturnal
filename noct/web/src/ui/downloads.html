v0.3.16-testnet — a network switch you can see. Changing between mainnet and testnet used to be an item in the application menu bar; after three separate reports of "there is no way to toggle", it is now a labelled pair of buttons at the top of the wallet itself, marking the chain you are on and switching in place. Also fixed: the chosen network was forgotten on every restart, a failed sync could wedge the wallet daemon permanently on "Starting the wallet service", and a node whose seeds are unreachable — a machine behind the same router as them, for instance — now has a way to be given a peer. v0.3.0 changed consensus: a node older than that cannot follow the current testnet chain, so if you are running v0.2.x or earlier, update or you will simply stop syncing.

The installer is not code-signed, so SmartScreen will warn, and it is not reproducible — Electron packaging is not deterministic, so its checksum proves only that your download arrived intact, not what is inside it. The command-line binaries it bundles are reproducible, and are the same ones in the archives above.

The checksum proves the file arrived intact. Whether the binary matches the source is a separate question, and from v0.1.4 you can answer it yourself for Linux: see reproducible builds. Releases up to v0.1.3, and Windows builds generally, are not reproducible — for those you are still trusting the author, and building from source remains the correct instinct. Build from source

Rust is pinned to 1.85.1 — the shielded pool’s orchard dependency requires it. The randomx feature needs cmake and a C++ toolchain.

git clone https://github.com/adamanto75/nocturnal
cd nocturnal/noct

cargo test --workspace                                # 578 tests
cargo build --release -p noct-wallet --bins           # noct-cli, noct-walletd
cargo build --release -p noct-node --features randomx # noctd, real PoW

Without --features randomx, noctd builds with a Keccak placeholder proof of work and cannot validate the real chain. It will reject every block. To sync a live network you need the RandomX build.

Run a testnet node

noctd --network testnet --data-dir ~/.noct-testnet
noct-cli new --network testnet --wallet testnet.key
noct-miner --address <YOUR_TESTNET_ADDRESS> --node 127.0.0.1:19334

The node RPC is an administrative interface: it can start mining and submit blocks. Keep it on loopback, or set a token and serve it over TLS. noctd refuses to start with an unauthenticated RPC bound to a non-loopback address.

Back up your seed phrase

A new wallet prints a 24-word phrase. It is the only way to recover the key. Write it down offline. Anyone holding it holds the coins.
